# Продажи видеоигр 2000–2013: подготовка и предобработка данных (Python)

## Описание проекта
Подготовка исторических данных о продажах видеоигр для дальнейшего анализа игровой индустрии.

**Цель:** очистить и структурировать датасет, отобрать актуальный период 2000–2013 годов и добавить категории оценок для последующего анализа.

**Данные:** около 17 тыс. игр — название, платформа, год выпуска, жанр, продажи по регионам (Северная Америка, Европа, Япония и другие), оценки критиков и пользователей, возрастной рейтинг.

**Что сделано:**
- названия столбцов приведены к snake_case, исправлены типы данных;
- обработаны пропуски: часть строк удалена, продажи заполнены средним по группе «платформа + год», оценки оставлены пустыми;
- найдены и удалены явные и неявные дубликаты (после нормализации текстовых значений);
- отобран срез 2000–2013 годов;
- добавлены категории оценок пользователей и критиков.

**Инструменты:** Python, pandas, Jupyter Notebook.

## Выводы
- Исходный датасет — **16 956 строк** с некорректными типами, пропусками и дубликатами. После предобработки удалено 512 строк (**около 3%**), осталось 16 444.
- Для анализа отобран период 2000–2013 годов: **12 781 строка** в датафрейме `df_actual`.
- Добавлены поля `user_score_category` и `critic_score_category`: высокая, средняя и низкая оценка, а также «без оценки».
- **Топ-7 платформ** по числу выпущенных игр: PS2, DS, Wii, PSP, X360, PS3, GBA — лидируют консоли Sony и Nintendo.
- Данные очищены и готовы для дальнейшего анализа.
