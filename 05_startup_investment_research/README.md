# Инвестиции в стартапы: в какую отрасль и как вкладываться (Python)

## Описание проекта
Итоговый проект модуля. Финансовая компания, работающая с венчурными инвестициями, рассматривает выход на рынок стартапов — покупку компаний и их развитие.

**Цель:** на исторических данных ответить на два вопроса — в какую отрасль целесообразно инвестировать и какой тип финансирования для этого уместен (по состоянию на 2015 год).

**Данные:** база стартапов — 54 294 компании с объёмами, типами и датами привлечённых инвестиций, плюс статистика возвратов средств по типам финансирования.

**Что сделано:**
- предобработка: очистка и приведение типов, обработка дат, удаление пустых дубликатов, нормализация текстовых значений (без неё один сегмент рынка распознавался как несколько: 848 сегментов вместо 394);
- инжиниринг признаков: группы по срокам финансирования, классификация сегментов на массовые, средние и нишевые;
- поиск выбросов методом межквартильного размаха отдельно по каждому сегменту;
- сравнение типов финансирования по объёму и популярности, динамика рынка по годам, рост сегментов и доля возвращаемых средств.

**Инструменты:** Python, pandas, matplotlib, seaborn, Jupyter Notebook.

## Выводы
- Финансирование распределено **крайне неравномерно**: компании с финансированием дольше года (30% датасета) получают 62% всех средств; 12% сегментов рынка вмещают 89% компаний.
- С 2005 по 2013 год объём финансирования вырос в 4,9 раза, а число раундов — в 13,6 раза: типичный раунд уменьшился с **4,5 до 0,56 млн $**. Деньги стали доступнее для большего числа компаний, но каждая получала меньше.
- **Венчурные инвестиции** — единственный тип, который лидирует одновременно по объёму (129 млрд $) и по числу компаний (18 820), и единственный, у которого доля возвращаемых средств росла все пять лет подряд.
- В 2014 году рынок сократился на 40%, но 10 из 48 массовых сегментов продолжили расти; лидер — **Medical (+171,6%)**.

**Рекомендации:** отрасль — Medical, запасной вариант — Internet (высокий темп, три года непрерывного роста, сопоставимый с лидерами объём); тип финансирования — венчурные инвестиции.
