# Сервис аренды самокатов GoFast: проверка продуктовых гипотез (Python, статистика)

## Описание проекта
Анализ данных сервиса проката самокатов GoFast за год: демография пользователей, поведение в поездках, выручка и выгода платной подписки.

**Цель:** проверить, выгодна ли сервису подписка Ultra по сравнению с бесплатным тарифом Free, и оценить продуктовые идеи — скидку за длинные поездки и доплату за превышение дистанции.

**Данные:** три таблицы — пользователи (возраст, город, тип подписки), 18 068 поездок (дистанция, длительность, дата) и тарифы (цена минуты, цена старта, абонентская плата).

**Что сделано:**
- предобработка: типы данных, месяц поездки, удаление дубликатов, округление длительности до целых минут (оплата поминутная);
- исследовательский анализ: города, доля подписчиков, возраст, распределение длительности поездок;
- расчёт помесячной выручки с каждого пользователя по тарифной формуле;
- проверка трёх гипотез t-тестами (одновыборочным и для независимых выборок, α = 0.05);
- моделирование длительности и дистанции поездок нормальным распределением (CDF, PPF).

**Инструменты:** Python, pandas, matplotlib, SciPy (`scipy.stats`), Jupyter Notebook.

## Выводы
- Без подписки ездят **54%** пользователей, с подпиской Ultra — **46%**. Средняя поездка — 17,8 мин, половина поездок укладывается в 14–22 минуты.
- **Подписчики ездят дольше:** 18,6 мин против 17,4 мин, p < 0,001. Разница значимая, но небольшая — около минуты.
- **Дистанция подписчиков не превышает оптимальные для износа 3130 м:** p = 0,92, оснований считать иначе нет.
- **Подписчики приносят больше выручки:** 359 ₽ против 322 ₽ в месяц (**+11%**), p < 0,001.
- Поездки длиннее 30 минут — лишь **около 2%**, а поездки 20–30 минут — **около 38%**. 90% поездок короче **4,5 км**.

**Рекомендации:** развивать подписку Ultra; привязывать промо для подписчиков к поездкам 20–30 минут, а не к редким поездкам длиннее 30 минут; использовать 4,5 км как ориентир порога дистанции для доплаты.
